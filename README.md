# Tech Challenge - Fase 1

## Objetivo

Desenvolver um modelo de Machine Learning para classificar pacientes quanto à presença de diabetes utilizando dados clínicos estruturados.

## Estrutura do projeto

```text
├── Dataset/
│   └── diabetes.csv
│
├── Notebooks/
│   └── tech_challenge_fase_1.ipynb
│
├── requirements.txt
├── Dockerfile
└── README.md
```

## Tecnologias utilizadas

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-Learn
- SHAP
- Matplotlib
- Seaborn

## Como executar

O projeto foi desenvolvido utilizando o **Google Colab**.

1. Clone este repositório.
2. Abra o notebook `Notebooks/tech_challenge_fase_1.ipynb` no Google Colab ou no Jupyter Notebook.
3. Certifique-se de que o arquivo `Dataset/diabetes.csv` esteja disponível na estrutura do projeto.
4. Execute as células na ordem em que estão apresentadas.

## Dataset

O projeto utiliza o **Pima Indians Diabetes Database**, disponível no Kaggle.

## Etapas do desenvolvimento

O notebook contempla as seguintes etapas:

- Análise exploratória dos dados
- Pré-processamento
- Construção dos modelos
- Validação cruzada
- Otimização de hiperparâmetros
- Avaliação dos modelos
- Interpretabilidade utilizando SHAP
- Discussão dos resultados
- Conclusão
